二、功能解析与取舍

字音同步与录音回顾已保存分路音频和段落时间；没有回放入口优先补齐。点击段落回听，进度拖动、倍速、来源切换、播放段落高亮。
基于录音的 AI 问答只有纪要与待办提取新增单场问答、原文依据、引用定位、取消、历史保存与导出。长资料逐段查阅，显示进度。
场景模板、结构化总结单一摘要格式提供工作会议、项目评审、访谈沟通、课堂笔记四种可维护模板；共用事实校验和任务依据规则。

三、使用流程

记录：创建空会议 → 按需开关麦克风 → 中文转写 → 标重点/写笔记 → 结束后分离和整理。

复盘：搜索文字或查看重点 → 点击段落时间回听 → 纠正文字/姓名 → 按场景重新生成纪要 → 确认待办。

追问：进入问答 → 选择常用问题或输入问题 → 本机逐段查阅 → 查看回答和引文 → 点击引文定位原文 → 保存/导出。

四、具体约束和验收

  • 暂停/继续录制产生的多个文件按会议时间定位；没有录音的间隔明确提示，不能播放错误来源。录制时禁止回放，暂停后可回听，继续录制前停止回放；开始录制、切换、删除和退出时停止播放器。
  • 旧会议缺少录音时保留原文；文件缺失提示原因，不删除资料。双路可独立回听，默认优先电脑声音。
  • 问答只以本场转写和笔记为材料，检查引用 ID 与逐字原文。无可核验引用时不保存肯定答案，显示材料中未找到明确答案。引用可核验不代表 AI 推理绝对正确，界面持续提示校对。
  • 长会议不只读取头部，按分组查阅全部材料。用户取消时不添加半条回答，不覆盖原纪要。问题最多 500 字。
  • 问答保存于所属会议；原文、笔记、姓名更新后提示重新核对。TXT 和 Markdown 导出包含问答、引用时间和姓名；SRT 保持只导出字幕。
  • 模板选择按会议保存。更换选择不覆盖旧纪要，重新生成才应用，并记录原生成模板。材料缺少的信息不补造；课堂内容不虚构作业。
  • 新增字段采用可选值兼容旧记录；复用已有 Ollama/Qwen3 或可用的系统本地 AI，不新增云端服务和模型下载。

五、验证范围
