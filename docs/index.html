中文实时转写

采集电脑声音与麦克风。暂停、继续，或随时关闭麦克风，电脑声音继续记录。也可导入本机录音。

02 / 辨认

会后区分说话人

在本机分析不同声音，支持整场改名、逐段纠正和指定人数重新分析。导出时保留姓名。

相近声音与抢话仍需校对
03 / 回顾

回听录音，定位原文

点击转写时间回听对应段落，支持拖动进度、前后跳转、倍速和声音来源切换。播放时高亮并可跟随文字。

暂停后可回听，继续录制前停止回放
04 / 追问

向这场会议提问

本地 AI 查阅本场原文和笔记，回答附可核对的引文，点击定位。问答随会议保存，可删除单条并在 TXT / Markdown 中导出。

长材料分段查阅，原文变更后提示核对

工作会议、项目评审、访谈沟通、课堂笔记四种模板。切换选择保留旧纪要，重新生成才应用；建议待办确认后再加入列表。

复用已有系统本地 AI 或 Ollama / Qwen3

适用条件与能力边界在这里说明。

哪些 Mac 可以使用？

需要 Apple Silicon Mac（M 系列芯片）与 macOS 26 或更新版本，系统中文识别模型需要可用。当前安装包不支持 Intel Mac。

Zoom 里静音后，还会记录我的麦克风吗？

Zoom 静音和会记的麦克风开关相互独立。需要停止记录你的麦克风时，请在会记里关闭麦克风；电脑声音继续转写。使用外放时也建议关闭会记麦克风，减少重复内容。

不装 AI 模型，能先用转写吗？

可以。在环境准备向导中取消“同时准备自动纪要与待办”，先准备中文识别。以后从“模型与环境”补齐即可。AI 不可用时，已有转写、笔记与会议记录仍可使用。

能准确区分每一个人，包括多人抢话吗？

当前提供会后本地说话人分离，支持改名与手动纠正。相近声线、极短接话、噪声和多人重叠仍可能误分；尚不能把同时讲话的每个人都完整转写出来，也不会自动获取 Zoom 参会人的真实姓名。纪要、问答和待办同样需要核对原文。

问答会把会议内容上传吗？回答可靠吗？

问答复用这台 Mac 上的本地 AI，只查阅本场转写与笔记，不上传会议内容。引用会逐字核对原文；没有可核验依据时明确提示。AI 仍可能误解或遗漏，引用校验不能保证推理正确，请核对原文。原文或笔记变更后，已保存回答会提示重新核对。

旧会议能回放吗？需要重新下载模型吗？

有本地录音的会议可回放，旧版只有文本的记录无法补回声音，但仍能查看和提问。0.5.0 新功能复用已有模型与环境，无需下载新的模型。

模型下载中断或失败怎么办？

在“模型与环境”中重新检查并重试。已完成的组件保留，Ollama 模型支持续传；运行环境压缩包中断后会重新下载。已有环境复用与实际安装已验证，当前网络下从空缓存完整下载纪要模型的流程尚未验证完成。

为什么 macOS 提示无法验证开发者？

目前测试版尚未完成 Apple Developer ID 签名与 Apple 公证。请确认安装包来自本项目 Release，并按发布说明核对校验值，再参考 Apple 官方打开说明。无需关闭系统安全保护。

下载列表是通用图标，应用图标是否缺失？

下载列表显示的 DMG 文件图标不代表应用图标。安装包内“会记.app”包含会记图标。打开 DMG 并拖入 Applications 安装即可。

怎么反馈问题或从源码构建？

可在 GitHub Issues 反馈，并说明系统版本、应用版本与复现步骤。请勿在公开问题中贴会议原文、录音或个人信息。构建方法与第三方组件说明见 项目 README。当前项目尚未指定源码许可证。
