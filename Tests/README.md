# 测试范围

完成模型准备后，运行 `bash test.sh`。它检查转写数据、会议保存、删除与恢复、麦克风独立开关、归档音频、姓名与人工纠正保存、导出、聚类及异常向量的 JSON 输出。使用临时目录和受控输入，不访问用户会议目录或采集真实音频。

以下集成测试源码保留，但测试输入和本机输出未发布：

- `SpeakerIntegrationTests.swift`：需要本机中文识别模型、`verification/中文双人会议示例.wav` 及已准备的说话人模型。
- `SpeakerAccuracyTests.swift`：还依赖 `verification/speaker-cases/` 下四人公开示例和单人、交替双人、短句合成输入及参考区间，以及冻结的旧版本与 ASR 对齐结果。
- `LocalAITests.swift`：需要可用的本地 AI 服务及模型。

`bash check-speakers.sh` 仅供已有这些本机测试资料的开发环境使用，不能在刚克隆的仓库中直接完成全部音频回归。它不是 `bash test.sh` 的必要步骤。

这台开发 Mac 上已用三段 AliMeeting 真人中文录音（各三分钟）评估说话人分析。0.4.2 自动模式严格时间错误率为 16.8%、28.9%、76.1%，包含重叠、未确定和漏声；短句和高抢话仍需校对。这三段同时用于开发与回归，不能当作独立盲测或整个数据集的成绩。本机录音、人工参考和详细输出没有上传至仓库。
